# Scrunch HUD (Scrunch Intelligence preview)

A free, translucent heads-up display that sits over Ableton Live, with an AI mix engineer you talk to (hold space in Live), bounce analysis, Audio-to-MIDI and Hum-to-MIDI. Bring your own AI key: add it in Settings the first time Scrunch opens.

**Download:** green **Code** button > **Download ZIP** (or the latest Release), unzip into Documents, then read `READ ME FIRST.txt`. Full details in `Details.md`.

macOS 12+, Ableton Live 12, Python 3.12 (setup fetches a private copy if needed). This is an early, unsigned preview: right-click > Open the first time.
